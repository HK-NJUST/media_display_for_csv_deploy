# 项目名称

## 简介
该项目用于读取 CSV 文件并显示媒体内容，支持标签的添加和删除。

## 可执行文件运行
1. 确保已安装 Python 3.9 及相关依赖。
2. 在终端中导航到项目目录。
3. 运行以下命令以启动可执行文件：
   ```bash
   ./dist/read_csv_show_media
   ```

## 功能介绍
- **读取 CSV 文件**：用户可以选择 CSV 文件进行读取。
- **显示媒体内容**：支持显示图片和视频文件。
- **标签管理**：
  - **添加标签**：用户可以添加单选或多选标签。
  - **删除标签**：用户可以选择并删除已有标签。
- **排序功能**：用户可以对表格中的数据进行升序或降序排序。
- **过滤功能**：用户可以通过选择特定值来过滤表格数据。
- **列可见性切换**：用户可以选择隐藏或显示特定列。
